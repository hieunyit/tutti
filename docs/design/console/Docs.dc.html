Automatic failover

A proxy moves a user's routing from an unavailable storage to the first healthy target of its policy. Two switches must be on: the policy, and failover.enabled in every proxy's config.

Enable it on a proxy

failover:
  enabled: true
  checkInterval: 5s
  after: 30s
  maxEventLag: 0

The target must already receive replication from the source, and its event lag must be within maxEventLag.
